# README artwork

These original illustrations were created with the built-in image-generation tool
on 2026-08-28 for Secure Share. They follow the application's existing navy,
blue, white, and slate palette in `app/static/css/style.css`.

They are conceptual brand artwork, not screenshots, security certifications,
or evidence of implemented encryption. The README's Mermaid diagrams and source
code remain the technical references. The existing favicon and app UI are unchanged.

## Assets

| File | Placement | Description |

The PNG files are copied into the repository so the README has no dependency on
an external image host or a local generation cache. Preserve the originals when
making variants; record any revised prompt here.

## Banner prompt

```text
Use case: ads-marketing
Asset type: wide GitHub README project banner, landscape approximately 3:1, 1920 by 640 composition.
Primary request: Create a polished original banner for Secure Share, a private owner-controlled file-sharing application.
Scene/backdrop: deep navy #071126 and #0b1734, a subtle restrained blue glow and barely visible fine technical grid.
Subject: a sculptural stack of white and translucent blue document sheets protected by a simple glass-blue shield, with two small connected account glyphs suggesting explicit sharing permissions. This is conceptual brand artwork, not a screenshot or architecture diagram.
Style/medium: premium editorial 3D illustration, crisp silhouettes, matte paper and softly frosted glass, refined controlled reflections; professional developer-project identity.
Composition/framing: generous safe margins, balanced wordmark and illustration in a wide editorial layout; large legible title and smaller subtitle, no visual clutter.
Lighting/mood: trustworthy, calm, purposeful, restrained blue rim lighting.
Color palette: the existing app palette: navy #071126, blue #2563eb and #3b82f6, white and slate #cbd5e1.
Text (verbatim): "Secure Share"
Subtitle (verbatim): "Private files. Explicit permissions. Owner-controlled access."
Typography: clean modern sans-serif, white, high contrast, exact spelling, title dominant.
Constraints: title and subtitle exactly once; no other text, no technology logos, no badges, no watermark, no fake app interface, no encryption algorithms or claims, no hackers, no hooded people, no neon cyberpunk, no stock-photo look. Keep all content inside the image without cropping.
```

## Supporting illustration prompt

```text
Use case: stylized-concept
Asset type: supporting README section illustration, wide landscape approximately 2:1.
Primary request: Create a matching editorial illustration for Secure Share that evokes private, owner-controlled document sharing.
Scene/backdrop: pale slate #f1f5f9 with ample clean space and soft grounded shadows.
Subject: a central blue private document tray holding a few crisp white file sheets, with a small simple shield motif; two abstract account tokens sit on separate small platforms, with a deliberate thin blue connection between the document tray and one approved account. Communicate intentional limited sharing, not public broadcast. Treat these as conceptual objects rather than a technical workflow diagram.
Style/medium: premium minimal isometric 3D still life, matte ceramic and paper, softly frosted blue material, consistent crisp geometry, same family as a navy-and-blue developer-project banner.
Color palette: navy #071126, blue #2563eb and #3b82f6, slate #cbd5e1, white, a tiny green approval accent.
Composition/framing: centered compact subject group across a wide canvas, generous margins, balanced objects, clean silhouette readable at README size.
Lighting/mood: soft studio light, calm and trustworthy, gentle ambient shadows.
Constraints: no text or letters, no logos, no watermarks, no interface screenshots, no graphs or explanatory labels, no biometric scans, no keys or encryption claims, no hacker imagery. Do not imply an implemented end-to-end encryption feature.
```
